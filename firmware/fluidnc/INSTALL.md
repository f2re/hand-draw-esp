# Первичная прошивка MKS DLC32 V2.1

Проект использует официальный **FluidNC для ESP32**. В репозитории хранится конфигурация станка, WebUI и средства развёртывания; двоичные файлы сторонней прошивки не копируются, чтобы не фиксировать устаревшую версию и не смешивать лицензии.

## Поддерживаемая плата

- MKS DLC32 V2.1;
- ESP32-WROOM;
- съёмные драйверы StepStick;
- штатный I2S-расширитель выводов платы;
- GPIO32/TTL-PWM для MG90S;
- GPIO36 и GPIO35 для X-min/Y-min.

Для другой ревизии нельзя загружать `config.yaml` без проверки схемы выводов.

## Перед прошивкой

1. Отключите внешний источник 12 В.
2. Отключите MG90S.
3. Отключите моторы.
4. Желательно временно снять StepStick-драйверы.
5. Подключите только USB.
6. Убедитесь, что кабель передаёт данные, а не только питание.

## Автоматическая подготовка официального пакета

Кроссплатформенный помощник скачивает последний стабильный release непосредственно из `bdring/FluidNC`, выбирает пакет для текущей ОС, сохраняет SHA-256 и распаковывает штатные установочные скрипты:

```bash
python3 scripts/install_fluidnc.py
```

Для запуска официального Wi-Fi-установщика:

```bash
python3 scripts/install_fluidnc.py --flash
```

Опасные операции не включаются автоматически:

```bash
# Стереть прежнюю прошивку, затем установить Wi-Fi-вариант
python3 scripts/install_fluidnc.py --erase --flash

# Также заменить локальную файловую систему; существующие файлы будут уничтожены
python3 scripts/install_fluidnc.py --erase --flash --install-fs
```

Перед подтверждением отключите 12 В, двигатели, MG90S и по возможности StepStick. Скрипт делегирует запись официальным `install-wifi`, `erase` и `install-fs` из release bundle; собственной перепаковки бинарной прошивки нет.

## Linux и другие POSIX-системы

1. Скачайте официальный release bundle FluidNC для Linux.
2. Распакуйте архив.
3. Перейдите в каталог установщика.
4. При наличии старой или неизвестной прошивки выполните:

```bash
sh erase.sh
```

5. Установите Wi-Fi-вариант:

```bash
sh install-wifi.sh
```

6. При первой чистой установке локальную файловую систему можно установить отдельно:

```bash
sh install-fs.sh
```

`install-fs.sh` стирает файлы локальной файловой системы. Не выполняйте его при обновлении без резервной копии `config.yaml` и пользовательских файлов.

При ошибке доступа к последовательному порту на Debian/Ubuntu:

```bash
sudo usermod -aG dialout "$USER"
```

После изменения группы необходимо завершить сеанс и войти снова.

## Windows x64

1. Скачайте официальный release bundle FluidNC для Windows x64.
2. Распакуйте архив.
3. При неизвестной старой прошивке запустите `erase.bat`.
4. Запустите `install-wifi.bat`.
5. Только для первой чистой установки при необходимости запустите `install-fs.bat`.
6. Для просмотра последовательного журнала используйте `fluidterm.bat`.

Для обычной ESP32 не используйте варианты файлов с суффиксом `_s3`.

## Первичная проверка FluidNC

В FluidTerm или другом терминале 115200 бод выполните:

```text
?
$$
$Limits
```

На этом этапе допустимо отсутствие механики. Недопустимы повторные перезагрузки, ошибки flash и аппаратные исключения.

## Подготовка файлов HandDraw ESP

В корне проекта:

```bash
python3 scripts/setup_project.py
python3 scripts/prepare_controller_bundle.py
```

Комплект появится в:

```text
release/handdraw-controller/
  config.yaml
  index.html.gz
  gcode/
  manifest.json
  INSTALL.txt
```

## Загрузка WebUI

После подключения FluidNC к сети:

```bash
python3 scripts/deploy_webui.py 192.168.1.50
```

Скрипт собирает интерфейс, загружает `/flash/index.html.gz`, считывает его обратно и проверяет SHA-256.

## Загрузка конфигурации

Только после проверки, что плата действительно MKS DLC32 V2.1:

```bash
python3 scripts/deploy_webui.py 192.168.1.50 --with-config
```

Затем перезагрузите ESP32 и прочитайте полный журнал. Не продолжайте при сообщениях:

```text
Ignored key
Pin is already used
ERR
Guru Meditation
```

## Безопасная наладка

В штатном `config.yaml` установлено:

```yaml
start:
  must_home: false
```

Это сделано только для первичного ввода в эксплуатацию и проверки направлений короткими перемещениями 1–5 мм. WebUI при этом всё равно блокирует запуск задания без homing в текущем сеансе. После проверки X-min, Y-min и нескольких стабильных `$H` установите `must_home: true` в конфигурации конкретного станка.

Предельные скорости и ускорения в репозиторном файле намеренно снижены. Профили линера, ручек, карандаша, пера и маркера выбираются в WebUI и используют ещё меньшие значения. Подробно: [`../../docs/FIRMWARE_AND_GCODE.md`](../../docs/FIRMWARE_AND_GCODE.md).

## Восстановление

Если контроллер перестал загружаться:

1. отключите 12 В и всю периферию;
2. подключите только USB;
3. выполните штатный `erase` из release bundle FluidNC;
4. повторите установку Wi-Fi-прошивки;
5. сначала проверьте чистый FluidNC;
6. затем загрузите WebUI;
7. конфигурацию загрузите последней.
