# FluidNC для HandDraw ESP

Полная инструкция первичной прошивки: [`INSTALL.md`](INSTALL.md). Архитектура генерации задания: [`../../docs/FIRMWARE_AND_GCODE.md`](../../docs/FIRMWARE_AND_GCODE.md).

`config.yaml` рассчитан на:

- MKS DLC32 V2.1;
- Cartesian XY;
- GT2 20T;
- NEMA17 1,8°;
- микрошаг 1/16;
- 80 шагов/мм;
- X 225 мм, Y 315 мм;
- RC-servo на GPIO32 как ось Z 0…5 мм.

## Консервативные пределы

| Ось | Скорость | Ускорение |
|---|---:|---:|
| X | 4800 мм/мин | 180 мм/с² |
| Y | 4200 мм/мин | 140 мм/с² |
| Z-servo | 240 мм/мин | 80 мм/с² |

WebUI выбирает более низкие значения под конкретный пишущий инструмент. Ограничения FluidNC не заменяют физическую калибровку, но не позволяют интерфейсу случайно превысить принятый диапазон осей.

## Важные команды

```text
$H                         homing
$X                         снять alarm
?                          отчёт состояния
!                          пауза
~                          продолжить
Ctrl-X                     программный reset
G0 Z5                      поднять инструмент
G0 Z0                      опустить инструмент
$SD/Run=/jobs/a.gcode      запустить задание с SD
```

## `must_home`

Репозиторный файл предназначен и для первого ввода в эксплуатацию:

```yaml
start:
  must_home: false
```

Это разрешает безопасные перемещения 1–5 мм до первого homing. WebUI всё равно не разрешает запуск задания без homing в текущем сеансе.

После проверки полярности обоих концевиков и нескольких устойчивых `$H` измените значение на `true` в конфигурации конкретного станка.

Драйверы работают в standalone STEP/DIR; UART не требуется. Микрошаг и ток задаются аппаратно по документации точной ревизии TMC2209.
