# Параметрическая механика HandDraw ESP

## Назначение

`plotter_parts.scad` теперь содержит не набор разложенных деталей, а единую параметрическую сборку с общей системой координат, сопряжёнными крепёжными интерфейсами и проверкой физического хода.

Номиналы вынесены в `component_dimensions.scad`. Перед выпуском рабочих STL этот файл необходимо скорректировать по `hardware/MEASUREMENTS.md`.

## Быстрый просмотр

Открыть `hardware/cad/plotter_parts.scad` в OpenSCAD и выбрать:

```scad
part = "assembly";
assembly_state = "center";
```

Состояния:

- `home` — управляемый минимум X/Y, перо поднято;
- `center` — центр рабочего поля;
- `max` — управляемый максимум X/Y;
- `motion_envelope` — полупрозрачные крайние и среднее положения;
- `exploded` — разнесённая сборка для проверки состава.

При F5/F6 в консоль выводятся:

- физический ход X/Y;
- управляемый ход;
- запас;
- начало рабочего поля;
- положение листа;
- шаги на миллиметр.

## Печатные детали

| Значение `part` | Количество | Назначение |
|---|---:|---|
| `y_carriage_plate` | 1 | общая пластина двух кареток Y, двух седел балки и зажима ремня |
| `beam_saddle` | 2 | отдельные регулируемые седла профиля 2020 |
| `x_carriage_plate` | 1 | каретка X с согласованными интерфейсами MGN12H, пера, серво и ремня |
| `pen_body` | 1 | направляющий корпус ползуна пера |
| `pen_slider` | 1 | подвижная цанга ручки |
| `pen_cap` | 1 | крышка и опора пружины |
| `servo_bracket` | 1 | кронштейн MG90S с отдельным двухточечным креплением |
| `y_motor_mount` | 1 | кронштейн двигателя Y для основания |
| `y_idler_mount` | 1 | кронштейн ролика Y для основания |
| `x_motor_mount` | 1 | кронштейн двигателя X для балки 2020 |
| `x_idler_mount` | 1 | кронштейн ролика X для балки 2020 |
| `belt_clamp` | 2 рабочих + 2 запасных | одинаковый интерфейс 18 мм для X и Y |
| `support_roller` | 1 | подвижная опора свободного конца балки с 625 |
| `endstop` | 2 | кронштейн выбранного микропереключателя |
| `cable_clip` | 6 | разгрузка жгутов |
| `fit_coupon` | 1 или больше | термовставки и зазоры ползуна |
| `electronics_base` | 1 после измерения платы | корпус MKS DLC32 |
| `electronics_lid` | 1 после измерения платы | крышка корпуса |

Старые имена `plate`, `x_carriage`, `motor_mount`, `idler_mount` оставлены как временные алиасы. Новые сборки должны использовать осевые имена.

## Исправленные сопряжения

### Пластина Y ↔ MGN12H

Две сетки 20 × 20 мм расположены на расстоянии 52 мм между центрами кареток.

### Пластина Y ↔ седла балки

Каждое седло использует четыре отверстия M4 на сетке 14 × 32 мм. Координаты задаются общими параметрами:

```scad
beam_saddle_mount_dx = 14;
beam_saddle_mount_dy = 32;
```

### Каретка X ↔ корпус пера

Четыре отверстия M4 используют общий параметрический интерфейс 32 × 40 мм.

### Каретка X ↔ сервопривод

Кронштейн MG90S имеет отдельные два отверстия M3 с вертикальным шагом 30 мм. Он больше не предполагается «висящим» рядом с держателем.

### Каретка ↔ ремень

Обе оси используют зажим с шагом отверстий 18 мм. Этот размер задаётся одним параметром `belt_clamp_pitch` и применяется на обеих ответных деталях.

### Двигатели и ролики

Кронштейны разделены на X и Y. Крепление к фанерному основанию и крепление к профилю 2020 больше не моделируются одной универсальной деталью.

## Расчётный ход

При номиналах:

```text
Y: 450 − (45,4 + 52) − 2×8 = 336,6 мм
X: 300 − 45,4 − 2×8 = 238,6 мм
```

Управляемое поле ограничено 225 × 315 мм. Полученный запас:

```text
X: 13,6 мм
Y: 21,6 мм
```

Этот запас не заменяет механическую проверку. После получения рельсов необходимо измерить длины кареток, торцевые расстояния и фактическое положение концевиков.

## Экспорт

Пример для одной детали:

```bash
openscad \
  -o build/stl/y_carriage_plate.stl \
  -D 'part="y_carriage_plate"' \
  hardware/cad/plotter_parts.scad
```

Проверка всех деталей:

```bash
python3 scripts/validate_cad.py --strict --render-all
```

OpenSCAD должен завершить компиляцию без предупреждений о пустой геометрии и без ошибок `assert`.

## Что ещё требует физической валидации

- точные посадки MGN12H-клонов;
- профиль и T-гайки;
- реальный MG90S и выбранный рог;
- жёсткость печатной каретки пера;
- геометрия тяги;
- точные кронштейны концевиков;
- отверстия корпуса конкретной подревизии MKS DLC32;
- отсутствие столкновений при ручном перемещении;
- настройка преднатяга опорного ролика.
