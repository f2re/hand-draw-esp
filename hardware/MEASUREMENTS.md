# Карта размеров и входной контроль деталей

Этот документ является обязательным шлюзом перед экспортом рабочего комплекта STL. Номинальные размеры в `hardware/cad/component_dimensions.scad` нужны для проектирования и проверки расчётов, но не заменяют измерение фактически купленных клонов.

## 1. Принцип

Для каждого критичного компонента фиксируются:

1. точная маркировка и ссылка на карточку либо технический паспорт;
2. ревизия;
3. номинальный размер из первичного источника;
4. фактический размер минимум в трёх точках;
5. максимальное отклонение;
6. принятое значение для CAD;
7. решение `ГОДЕН / ДОРАБОТАТЬ CAD / БРАК`.

Рабочая таблица: `hardware/measurements.example.csv`. Сделайте копию `hardware/measurements.csv`; этот локальный файл должен содержать данные конкретной сборки.

## 3. Инструменты

Минимально необходимы:

- штангенциркуль 0–150 мм с разрешением 0,01 мм;
- металлическая линейка 500 мм;
- поверочный угольник;
- плоская стеклянная или поверочная поверхность;
- набор щупов, желательно;
- мультиметр;
- омметр или тот же мультиметр для обмоток;
- весы с шагом 1 г, желательно;
- маркер и бирки для проводов.

Перед серией измерений проверить ноль штангенциркуля и повторяемость на известном размере.

## 4. Что измерять

### 4.1. Направляющие MGN12

Для каждого рельса:

- фактическую общую длину;
- расстояние от каждого торца до первого отверстия;
- шаг минимум между четырьмя соседними отверстиями;
- ширину и высоту рельса;
- диаметр сквозного отверстия и зенковки;
- прямолинейность на плоской поверхности;
- свободный ход каретки по всей длине.

Для каждой MGN12H:

- длину, ширину и общую высоту сборки;
- сетку четырёх резьбовых отверстий;
- фактическую глубину резьбы;
- люфт и равномерность перемещения.

Не снимать каретку с рельса без транспортировочной вставки.

### 4.2. Профиль 2020

Измерить:

- фактическое сечение по двум осям;
- ширину горловины паза;
- доступную глубину паза;
- длину;
- прямолинейность;
- совместимость выбранных T-гаек M5.

Параметр `profile_fit_clearance` задаётся только после печати короткого пробного седла.

### 4.3. NEMA17

Зафиксировать точный артикул. Измерить и сверить с паспортом:

- 42 × 42 мм;
- длину корпуса;
- шаг четырёх монтажных отверстий;
- диаметр центрирующего бурта;
- диаметр, длину и D-срез вала;
- длину провода;
- сопротивление обеих фаз;
- номинальный ток фазы.

Два рабочих двигателя должны быть одной модели. Настройка TMC2209 выполняется только после фиксации номинального тока.

### 4.4. TMC2209

Зафиксировать изготовителя и ревизию StepStick. Проверить:

- стандартный, а не EZ-формат;
- ориентацию `VMOT/GND/VIO/EN/STEP/DIR`;
- номинал измерительных резисторов;
- способ задания MS1/MS2;
- точку измерения Vref;
- наличие радиатора.

Для FYSETC V3.0/3.1 в автономном режиме 1/16 соответствует `MS1=VIO`, `MS2=VIO`. Для этой ревизии опубликована оценка `Irms = 0,71 × Vref`, то есть `Vref ≈ 1,41 × Irms`. Эту формулу нельзя переносить на неизвестный модуль без проверки его схемы и резисторов.

Начальный ток для двигателя 1,5 А следует выбирать ниже паспортного и повышать только при пропусках шагов, контролируя температуру. Итоговое значение фиксируется в журнале ввода в эксплуатацию.

### 4.5. MG90S

Измерить:

- корпус;
- расстояние между монтажными ушами;
- диаметры отверстий;
- положение выходного вала относительно центра корпуса;
- фактический комплект рогов;
- расстояния отверстий на выбранном роге;
- безопасный угловой диапазон без упора редуктора;
- ток при движении и кратковременном удержании, если есть лабораторный БП.

Сервопривод должен быть позиционным, а не непрерывного вращения.

### 4.6. Держатель ручки и пружина

Для каждой планируемой ручки:

- диаметр корпуса в зоне зажима минимум в трёх сечениях;
- конусность;
- длину до наконечника;
- необходимый нажим для непрерывной линии.

Для пружины:

- наружный диаметр;
- диаметр проволоки;
- свободную длину;
- длину при усилии 1 Н, 2 Н и 3 Н.

Целевой рабочий нажим первой версии — около 1–3 Н. Сервопривод только поднимает ползун; нажим создаёт пружина.

### 4.7. Концевики

Зафиксировать конкретную модель. Измерить:

- корпус;
- шаг и диаметр отверстий;
- положение рычага в свободном и сработавшем состоянии;
- ход от щелчка до жёсткого упора;
- расположение COM/NC/NO.

Кронштейн размещается так, чтобы щелчок происходил за 2–5 мм до механического упора.

### 4.8. MKS DLC32

Зафиксировать подревизию `V2.1_001`, `V2.1_002` или `V2.1_003`. От выбранного левого нижнего угла платы измерить:

- контур X/Y;
- координаты центров всех крепёжных отверстий;
- диаметр отверстий;
- максимальную высоту компонентов;
- зоны доступа к USB, питанию, SD, драйверам и разъёмам;
- требуемую высоту радиаторов TMC2209.

До этого корпус `electronics_base` является только параметрическим черновиком и не должен печататься как финальная деталь.

## 5. Допуски и решения

| Интерфейс | Целевой результат |
|---|---|
| M3 через печатную деталь | 3,2–3,4 мм после печати без растрескивания |
| M4 через печатную деталь | 4,3–4,5 мм |
| M5 через печатную деталь | 5,3–5,5 мм |
| Подвижный ползун пера | свободное движение под собственным весом без заметного углового люфта |
| Посадка профиля в седло | ручная установка без молотка; боковой люфт устраняется винтами |
| Зажим GT2 | ремень не выскальзывает при ручной нагрузке и не повреждает корд |
| MG90S | корпус не изгибается при затяжке; рог не упирается в крайних положениях |
| Подшипник 625 | свободное вращение без выраженного радиального люфта |

## 6. Расчётные проверки после ввода размеров

Запустить:

```bash
python3 scripts/validate_cad.py --report build/cad-validation.json
```

Сценарий рассчитывает:

- физический и управляемый ход X/Y;
- запас до механических узлов;
- масштаб GT2/20T при 1/16;
- оценку прогиба балки 2020;
- идеальную силу MG90S на выбранном радиусе рога;
- оценку окружной силы шагового двигателя.

При установленном OpenSCAD:

```bash
python3 scripts/validate_cad.py --strict --render-all
```

Команда должна скомпилировать каждую печатную деталь и сборочные режимы без ошибок.

## 7. Запрет перехода к серии

Полный комплект пластика не печатать, пока не выполнены все пункты:

- получены и измерены обе направляющие;
- зафиксирован точный двигатель;
- зафиксирован точный TMC2209;
- получен MG90S;
- получены ролики, шкивы, ремень и концевики;
- пройден `fit_coupon`;
- пройдено пробное седло профиля;
- пройден пробный ползун пера;
- OpenSCAD собрал все детали;
- подтверждены расчётные ходы 225 × 315 мм.
