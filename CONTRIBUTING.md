# Участие в разработке

## Проверка изменений

Перед коммитом выполнить:

```bash
npm test
```

Дополнительная проверка автономной страницы в Chromium:

```bash
python -m pip install playwright
CHROMIUM_PATH=/usr/bin/chromium python3 tests/browser_smoke.py --no-screenshot
```

Изменения WebUI считаются завершёнными только после пересборки `dist/index.html`, `dist/index.html.gz` и `dist/manifest.json` командой `npm run build`.

## Требования к изменениям

- Не добавлять CDN и обязательные сетевые зависимости: интерфейс должен работать полностью автономно.
- Геометрия предпросмотра и G-code должна происходить из одного массива полилиний.
- Не обходить проверку границ рабочего поля.
- Любые изменения путей FluidNC сопровождать тестом команды `$SD/Run` или `$LocalFS/Run`.
- Новые параметры шрифта должны сохраняться в проекте и не ломать формат `hand-draw-font-v1`.
- Для новых печатных деталей указывать материал, ориентацию, заполнение и критические посадки.
- Схемы и фотографии не должны противоречить `hardware/WIRING.md`, `hardware/ASSEMBLY.md` и `firmware/fluidnc/config.yaml`.

## Аппаратные изменения

Изменения карты выводов и силовой схемы требуют отдельного описания риска. Нельзя предлагать питание MG90S от 12 В, установку StepStick под напряжением или программную кнопку как замену аппаратному отключению питания.
