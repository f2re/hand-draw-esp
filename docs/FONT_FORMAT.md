# Формат однолинейного шрифта

Идентификатор формата: `hand-draw-font-v1`.

## Пример

```json
{
  "format": "hand-draw-font-v1",
  "meta": {
    "name": "Почерк Ивана",
    "author": "Иван Иванов",
    "license": "CC BY 4.0",
    "description": "Однолинейный шрифт для плоттера",
    "version": "1.0.0",
    "unitsPerEm": 1,
    "capHeight": 1,
    "baseline": 0
  },
  "glyphs": {
    "А": [
      {
        "width": 0.9,
        "strokes": [
          [[0.05, 0], [0.45, 1], [0.85, 0]],
          [[0.22, 0.43], [0.68, 0.43]]
        ]
      }
    ]
  }
}
```

## Координаты

- X растёт вправо.
- Y растёт вверх от базовой линии.
- Нормальная высота прописной буквы равна 1.
- Значения могут выходить за диапазон 0…1 для выносных элементов.
- `width` — шаг курсора после знака, не обязательно равен максимальному X.

## Варианты

Значение `glyphs[character]` — массив вариантов. Каждый вариант должен иметь минимум один штрих из двух точек. При наборе выбирается один вариант по зерну генератора.

## Метаданные

`author` и `license` обязательно должны отражать право пользователя распространять файл. Интерфейс не накладывает лицензию автоматически.

## Совместимость

Неизвестные дополнительные поля должны игнорироваться. Изменение, несовместимое с первой версией, потребует нового значения `format`.

## Рекомендации автору

- Не обводить буквы по контуру; рисовать реальное движение пера.
- Разделять штрихи там, где перо должно быть поднято.
- Создать 2–4 варианта часто повторяющихся букв.
- Не добавлять случайный шум непосредственно в глиф: вариативность задаётся при раскладке.
- Проверять текст на высоте 3,5; 5; 7 и 10 мм.
- Для связного почерка располагать начало и конец совместимых букв на близкой высоте.
