# Калибровка

Интерактивный порядок ввода в эксплуатацию и сохранение профиля станка описаны в [`COMMISSIONING.md`](COMMISSIONING.md).

## 1. Проверка без ремней

- Каретки MGN12H должны проходить весь ход без клина.
- Балка X должна оставаться перпендикулярной Y.
- Правый опорный ролик касается основания с минимальным преднатягом.
- Подвижный держатель пера опускается под пружиной и свободно возвращается.

## 2. Пары обмоток

Мультиметром найти две пары проводов каждого NEMA17. Провода одной пары подключаются к A1/A2, второй — к B1/B2. Случайное чередование проводов вызывает дрожание вместо вращения.

## 3. Направления

Снять ручку и выполнить перемещения по 1 мм. При неверном направлении менять логический суффикс `:low` у `direction_pin` либо развернуть одну пару обмотки при снятом питании. Не менять одновременно оба способа.

## 4. Концевики

Использовать COM и NC. До homing выполнить `$Limits` или соответствующую диагностическую команду и вручную нажать каждый переключатель. Должен меняться только нужный вход.

Если логика обратная, изменить:

```yaml
limit_neg_pin: gpio.36:low
```

или аналогично для Y. Решение принимается по фактическому состоянию платы, а не по цвету проводов.

## 5. Шаги на миллиметр

Для двигателя 1,8°, микрошагов 1/16, шкива 20T и ремня с шагом 2 мм:

```text
200 × 16 / (20 × 2) = 80 шагов/мм
```

Нарисовать линию или квадрат 100 мм и измерить. Коррекция:

```text
новое steps_per_mm = старое steps_per_mm × заданный размер / измеренный размер
```

Пример: получено 99,4 мм:

```text
80 × 100 / 99,4 = 80,483
```

X и Y корректируются независимо.

## 6. Перпендикулярность

Квадрат 100 × 100 мм может иметь правильные стороны, но разные диагонали. Это механическая ошибка угла, которую нельзя исправлять `steps_per_mm`.

1. Измерить обе диагонали.
2. Ослабить крепление балки X.
3. Малой коррекцией повернуть балку.
4. Повторить тест.

Цель для данной простой конструкции:

- стороны: ±0,3 мм;
- разность диагоналей: не более 0,5 мм;
- повторяемость начала линии: около ±0,2 мм.

## 7. Сервопривод

Первый тест — без ручки:

```gcode
G21
G90
G0 Z5
G4 P1
G0 Z0
G4 P1
G0 Z5
```

Рог не должен упираться в механику ни при Z0, ни при Z5. Если ход слишком велик, уменьшить диапазон импульсов в `config.yaml` или переставить тягу ближе к оси рога.

Рабочий подъём наконечника: 3–5 мм. Больший ход только увеличивает время и нагрузку.

## 8. Нажим

- Линер: минимальный нажим, достаточный для непрерывной линии.
- Гелевая ручка: немного больше; избегать размазывания.
- Шариковая ручка: больший нажим, но без заметного прогиба балки.
- Автоматический карандаш: лёгкий нажим и малая скорость.

Пружина должна компенсировать неровность листа, а не прижимать балку к основанию.

## 9. Скорости и профили

WebUI содержит консервативные стартовые профили:

| Инструмент | Рисование | Холостой ход |
|---|---:|---:|
| Линер | 1200 мм/мин | 3600 мм/мин |
| Гелевая ручка | 850 | 2800 |
| Шариковая ручка | 1050 | 3400 |
| Карандаш | 760 | 2700 |
| Перо с тушью | 520 | 2100 |
| Маркер | 650 | 2300 |
| Homing seek | 1800 | — |
| Homing feed | 300 | — |

Порядок настройки:

1. начать с профиля без увеличения скорости;
2. выполнить простой текст и рисунок;
3. проверить пропуски, размазывание, прогиб и нагрев;
4. менять один параметр за один тест;
5. сохранить принятые значения в рабочем профиле браузера.

Для пера с тушью нельзя оценивать режим только по скорости: важны направление штриха, запас туши, бумага и отсутствие обратного движения. Подробно: [`FIRMWARE_AND_GCODE.md`](FIRMWARE_AND_GCODE.md).
