# Полный маршрут: от закупки до первого рисунка

Эта инструкция задаёт обязательный порядок работ. Не переходите к следующему этапу, пока не выполнены критерии приёмки предыдущего. Конструкция рассчитана на **MKS DLC32 V2.1 (ESP32)**, два NEMA17, TMC2209, ремни GT2, MGN12H и позиционный сервопривод MG90S.

## 0. Зафиксированная конфигурация

| Параметр | Значение |
|---|---|
| Поле станка | 225 × 315 мм |
| Лист | A4, неподвижный |
| Ось Y | MGN12H 450 мм, две каретки |
| Ось X | профиль 2020 длиной 330–350 мм + MGN12H 300 мм |
| Передача | GT2 6 мм, 20 зубьев |
| Двигатели | 2 × NEMA17, 1,8° |
| Контроллер | MKS DLC32 V2.1, ESP32-WROOM |
| Драйверы | TMC2209 StepStick, автономный STEP/DIR |
| Подъём пера | MG90S 180°, виртуальная ось Z |
| Питание | 12 В / 5 А; отдельные 5,0 В для MG90S |

Изменение шкива, микрошагов, размера поля или платы требует корректировки `firmware/fluidnc/config.yaml` и повторной калибровки.

## 1. Закупка

1. Откройте [`hardware/BOM.md`](../hardware/BOM.md).
2. Используйте [`hardware/bom.csv`](../hardware/bom.csv) как рабочую таблицу закупки.
3. Сначала закажите критичные по посадкам детали:
   - обе направляющие MGN12H;
   - MG90S;
   - NEMA17;
   - концевые выключатели;
   - MKS DLC32 V2.1;
   - ролики и подшипники.
4. Не печатайте полный комплект пластика до получения этих компонентов.

Критерий завершения: маркировка платы и драйверов проверена, Y-рельс имеет две каретки, сервопривод является позиционным 180°, а не непрерывного вращения.

## 2. Измерение и 3D-печать

1. Измерьте штангенциркулем купленные детали.
2. Откройте [`hardware/cad/plotter_parts.scad`](../hardware/cad/plotter_parts.scad).
3. Скорректируйте параметрические посадки.
4. Сначала напечатайте `fit_coupon`, участок ползуна пера и один зажим ремня.
5. После проверки напечатайте остальной комплект по [`hardware/PRINTING.md`](../hardware/PRINTING.md).

Критерии завершения:

- ползун пера перемещается без закусывания и заметного качания;
- M3 не раскалывает деталь;
- ремень удерживается без пережатия корда;
- MG90S устанавливается без изгиба корпуса;
- отверстия MGN12H совпадают с фактическими блоками.

## 3. Механическая сборка

Выполняйте [`hardware/ASSEMBLY.md`](../hardware/ASSEMBLY.md) в указанной последовательности:

1. плоское основание и ножки;
2. один рельс Y и две каретки;
3. ременной привод Y;
4. перпендикулярная балка X;
5. рельс и привод X;
6. лёгкая опора свободного конца балки;
7. держатель пера и сервомеханизм;
8. концевики;
9. укладка кабелей.

До электроподключения каретки должны проходить весь рабочий ход вручную без клина. Ремень натягивается только до исчезновения провиса; чрезмерное натяжение ухудшает геометрию и нагружает подшипники.

## 4. Электрика

Используйте только [`hardware/WIRING.md`](../hardware/WIRING.md) и схему [`docs/images/wiring.svg`](images/wiring.svg).

Обязательный порядок:

1. 12 В отключены, USB отключён.
2. Проверена ориентация TMC2209.
3. Найдены пары обмоток каждого NEMA17.
4. DC/DC настроен мультиметром на **5,0 В без сервопривода**.
5. Объединены GND платы, DC/DC и MG90S.
6. Сигнал MG90S подключён к GPIO32/TTL-PWM, питание серво — только к DC/DC.
7. Концевики подключены через COM+NC.
8. Предохранитель 5 А установлен максимально близко к входу 12 В.

Критерий завершения: короткого замыкания между +12 В и GND нет, на линии серво 5,0 В, все провода разгружены от натяжения во всём диапазоне хода.

## 5. Первичная прошивка ESP32

Следуйте [`firmware/fluidnc/INSTALL.md`](../firmware/fluidnc/INSTALL.md).

На первом этапе подключается только плата по USB; 12 В, моторы и сервопривод отключены. Подготовьте и установите официальный Wi-Fi-вариант FluidNC:

```bash
python3 scripts/install_fluidnc.py
python3 scripts/install_fluidnc.py --flash
```

Затем загрузите:

- `firmware/fluidnc/config.yaml`;
- собранный `dist/index.html.gz`.

После перезагрузки прочитайте полный журнал. Сообщения `Ignored key`, `Pin is already used` и `ERR` необходимо устранить до подключения механики.

## 6. Подготовка программной части

Автоматическая подготовка среды:

```bash
python3 scripts/setup_project.py
```

Или вручную:

```bash
python3 -m venv .venv
. .venv/bin/activate          # Windows: .venv\\Scripts\\activate
python -m pip install -r requirements-dev.txt
npm test
```

Сборка автономного интерфейса:

```bash
python3 scripts/build_webui.py
```

Подготовка переносимого комплекта контроллера:

```bash
python3 scripts/prepare_controller_bundle.py
```

Результат находится в `release/handdraw-controller/` и в архиве `release/handdraw-controller.zip`.

## 7. Развёртывание WebUI и конфигурации

Когда FluidNC доступен по сети:

```bash
python3 scripts/deploy_webui.py handdraw.local
```

Конфигурацию передавайте отдельно и только после проверки платы:

```bash
python3 scripts/deploy_webui.py handdraw.local --with-config
```

При включённой авторизации:

```bash
python3 scripts/deploy_webui.py 192.168.1.50 \
  --user admin \
  --password 'пароль' \
  --with-config
```

После изменения `config.yaml` перезагрузите контроллер и снова проверьте журнал запуска.

## 8. Первый пуск без ручки

1. Отключите 12 В.
2. Установите драйверы и подключите моторы.
3. Отведите каретки от упоров.
4. Включите питание и соединитесь с WebUI.
5. Проверьте `$Limits`, нажимая каждый концевик рукой.
6. Проверьте перемещения X/Y по 1–5 мм.
7. Исправьте направление в конфигурации, а не перестановкой проводов под напряжением.
8. Запустите `gcode/servo_test.gcode` без ручки.
9. Проверьте homing `$H`.

Критерий завершения: оси движутся в ожидаемом направлении, концевики останавливают правильную ось, сервопривод не упирается механически и не нагревается.

## 9. Калибровка и первый рисунок

Следуйте [`docs/CALIBRATION.md`](CALIBRATION.md):

1. квадрат 100 × 100 мм;
2. проверка диагоналей;
3. корректировка `steps_per_mm` только после устранения механического перекоса;
4. рамка A4;
5. установка ручки;
6. подбор пружины и высоты Z;
7. технический текст;
8. SVG-рисунок.

Целевые критерии для первой рабочей версии:

- сторона квадрата 100 мм: отклонение не более ±0,3 мм;
- разность диагоналей квадрата: не более 0,5 мм;
- повторная линия не расходится более чем на 0,3 мм;
- перо полностью отрывается при холостом ходе;
- бумага не продавливается;
- G-code не выходит за поле 225 × 315 мм.

## 10. Восстановление

При некорректной работе:

1. снимите 12 В;
2. отключите моторы и сервопривод;
3. подключите плату только по USB;
4. при необходимости выполните штатный `erase` из комплекта FluidNC;
5. повторно установите Wi-Fi-прошивку;
6. загрузите только проверенный `config.yaml`;
7. повторите ввод в эксплуатацию с этапа 8.

Программная кнопка остановки не заменяет аппаратное снятие питания.
