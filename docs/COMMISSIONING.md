# Первичная настройка станка

Этот этап выполняется один раз после сборки и повторяется после замены двигателя, драйвера, концевика, сервопривода, пружины, держателя пера или упора бумаги.

## 1. Выберите наладочную конфигурацию

Для первого включения используйте `firmware/fluidnc/config.yaml`:

- `must_home: false`;
- аппаратные пределы выключены;
- разрешены короткие перемещения 1–5 мм для проверки направлений.

`config-production.yaml` применяется только после завершения всех проверок в WebUI.

## 2. Создайте профиль станка

Откройте **Станок → Ручное управление и диагностика**.

1. Выберите номинальный профиль `A4 · центрированный`.
2. Задайте собственное название, например `HandDraw №1`.
3. Введите фактическое положение угла листа относительно машинного нуля.
4. Сохраните профиль.

Профиль хранит:

- смещение листа X/Y;
- steps/mm обеих осей;
- положения пера вверх и вниз;
- версию FluidNC и имя конфигурации;
- результаты проверки направлений, концевиков и homing.

Экспортируйте профиль после приёмки. Файл `.handdraw-machine.json` является резервной копией параметров конкретного экземпляра.

## 3. Опросите контроллер

Нажмите **Опросить контроллер**. Интерфейс последовательно запрашивает:

- `$I` — сборку FluidNC;
- `$Config/Filename` — активный YAML;
- `$ESP200` — состояние SD-карты.

Для штатной сборки ожидается версия, указанная в `firmware/fluidnc/fluidnc-lock.json`. Несовпадение не блокирует ручное управление, но рабочую конфигурацию следует включать только после отдельной проверки совместимости.

## 4. Проверьте направления

Снимите ручку. Установите шаг jog 1 мм.

1. Нажмите X+ и убедитесь, что перо движется вправо.
2. Нажмите Y+ и зафиксируйте принятое направление по листу.
3. При ошибке снимите питание и измените только один способ инверсии: либо `direction_pin`, либо одну пару обмотки.
4. Отметьте обе проверки в профиле.

## 5. Проверьте концевики

Нажмите **Проверить концевики 8 с** и поочерёдно нажмите X и Y.

- должен изменяться только соответствующий вход;
- отпущенный NC-концевик не должен выглядеть как обрыв;
- провод следует пошевелить во время проверки;
- каретка должна успевать нажать переключатель до механического упора.

После успешной проверки отметьте X и Y.

## 6. Повторите homing

Выполните не менее трёх последовательных циклов:

1. homing;
2. короткое перемещение от нуля;
3. повторный homing.

Начальная точка должна повторяться, а каретка не должна ударяться в упор. Затем отметьте проверку homing.

## 7. Калибруйте steps/mm

Командуйте линию 100 мм и измерьте её штангенциркулем или точной линейкой.

Формула:

```text
новое значение = текущее значение × заданная длина / измеренная длина
```

В WebUI заполните измеренное X и Y, нажмите **Рассчитать**, затем скачайте YAML-фрагмент. Перенесите значения в обе конфигурации FluidNC, перезагрузите контроллер и повторите измерение.

Разность диагоналей квадрата не исправляется steps/mm: это ошибка перпендикулярности механики.

Экспортированный профиль можно применить к обеим конфигурациям без ручного поиска строк:

```bash
python3 scripts/apply_machine_profile.py HandDraw-No1.handdraw-machine.json
```

Сценарий создаст `config-commissioning.yaml` и `config-production.yaml` в `build/machine-config/<имя>/`. Для загрузки конкретного файла:

```bash
python3 scripts/deploy_webui.py handdraw.local \
  --config-file build/machine-config/HandDraw-No1/config-commissioning.yaml
```

## 8. Калибруйте перо

- рог MG90S не должен упираться при Z0 и Z5;
- рабочий отрыв наконечника — 3–5 мм;
- пружина должна компенсировать неровность бумаги, а не прогибать балку;
- после смены инструмента повторите тест пера.

Сохраните окончательные Z в профиле станка.

## 9. Перейдите на рабочую конфигурацию

Только когда WebUI показывает **Готов к рабочему профилю**:

```bash
python3 scripts/deploy_webui.py handdraw.local \
  --with-config \
  --config-profile production
```

Рабочая конфигурация включает обязательный homing и аппаратные пределы X/Y. После перезагрузки снова проверьте журнал старта, homing, тест пера и рамку с поднятым инструментом.
