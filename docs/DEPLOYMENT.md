# Установка FluidNC и WebUI

## 1. Подготовка платы

Проект рассчитан на MKS DLC32 V2.1. Перед включением:

- снять питание;
- проверить ориентацию TMC2209;
- не подключать MG90S к 12 В;
- оставить ручку снятой;
- механически отвести каретки от упоров.

FluidNC устанавливается из официального release bundle, закреплённого в `firmware/fluidnc/fluidnc-lock.json`. Краткий порядок:

- Linux/POSIX: `sh install-wifi.sh`; при неизвестной старой прошивке сначала `sh erase.sh`; `sh install-fs.sh` применяется только для первой чистой установки или осознанного стирания local filesystem.
- Windows x64: `install-wifi.bat`; при необходимости `erase.bat`; для первой чистой файловой системы — `install-fs.bat`.
- Для обычной ESP32 не использовать варианты `_s3`.

Точная последовательность и восстановление описаны в [`firmware/fluidnc/INSTALL.md`](../firmware/fluidnc/INSTALL.md). После прошивки сначала открыть FluidTerm/последовательную консоль и убедиться, что плата стартует без аппаратных ошибок.

## 2. Конфигурация

Для первичной наладки используется `firmware/fluidnc/config.yaml`. После проверки направлений, NC-концевиков и повторяемого homing применяется `firmware/fluidnc/config-production.yaml`.

Передача наладочного профиля:

```bash
python3 scripts/deploy_webui.py 192.168.1.50 --with-config
```

Передача рабочего профиля:

```bash
python3 scripts/deploy_webui.py 192.168.1.50 \
  --with-config \
  --config-profile production
```

После перезагрузки необходимо прочитать весь журнал старта. Сообщения `Ignored key`, `Pin is already used` и другие `ERR` недопустимы.

Наладочный профиль использует `must_home: false` и `hard_limits: false`. Рабочий профиль включает обязательный homing и hard limits; редактировать эти отличия вручную больше не требуется.

## 3. Сборка интерфейса

```bash
python3 scripts/build_webui.py
```

Результат:

- `dist/index.html` — читаемая автономная страница;
- `dist/index.html.gz` — файл для ESP32;
- `dist/manifest.json` — размеры и SHA-256.

## 4. Загрузка интерфейса

```bash
python3 scripts/deploy_webui.py 192.168.1.50
```

Скрипт сначала сохраняет существующие файлы в локальный каталог `backups/<UTC-время>`, загружает временный файл, проверяет SHA-256, пытается завершить замену через WebDAV `MOVE` и при необходимости использует проверенный резервный `PUT`. При ошибке выполняется откат предыдущего содержимого.

При включённой HTTP-аутентификации:

```bash
python3 scripts/deploy_webui.py handdraw.local \
  --user admin \
  --password 'пароль'
```

## 5. SD-карта

Рекомендуется FAT32. Логический каталог заданий на карте — `/jobs`; в HTTP-файловой системе FluidNC он доступен как `/sd/jobs`. WebUI создаёт каталог через WebDAV `MKCOL`, записывает временный файл, читает его обратно и сравнивает содержимое побайтово. Затем выполняется `MOVE` либо проверенная резервная запись итогового имени. После проверки запускается логический путь `$SD/Run=/jobs/<имя>`.

Для первого теста можно вручную создать `jobs` в корне SD-карты и скопировать:

- `gcode/servo_test.gcode`;
- `gcode/calibration_square_100mm.gcode`;
- `gcode/a4_frame.gcode`.

## 6. Сеть

Основной вариант — открыть интерфейс по адресу самой ESP32. Тогда HTTP, WebDAV и WebSocket имеют один origin и не требуют CORS.

Поле «Адрес контроллера» предназначено для случаев, когда интерфейс открыт отдельно. Некоторые браузеры блокируют обращения с HTTPS-страницы к HTTP-контроллеру и междоменные загрузки. При таких ограничениях использовать страницу с самой ESP32.

## 7. Обновление

1. Собрать новую страницу.
2. Остановить станок.
3. Передать `index.html.gz`.
4. Выполнить жёсткое обновление браузера.
5. Проверить версию и генерацию тестового текста.

Нельзя обновлять WebUI и конфигурацию во время движения.

## 8. Контроль после установки

1. Открыть WebUI и убедиться, что сжатая страница загрузилась без внешних сетевых запросов.
2. Подключиться к FluidNC и дождаться состояния `Idle` или ожидаемого `Alarm` до homing. При открытии страницы с ESP32 соединение выполняется автоматически.
3. Проверить `?`, `$Limits`, `$X` и `$H` без установленной ручки.
4. Выполнить тест пера и рамку с поднятым инструментом через мастер WebUI, затем квадрат 100 × 100 мм.
5. Проверить, что SD-файл запускается именно командой `$SD/Run=/jobs/имя.gcode`.
6. Не обновлять страницу при `Run`, `Jog` или `Hold`.


## Закреплённая версия FluidNC

`scripts/install_fluidnc.py` читает `firmware/fluidnc/fluidnc-lock.json` и по умолчанию не обращается к `releases/latest`. Команды `--tag` и `--latest` считаются явным отклонением от проверенного набора. Перед обновлением lock-файла необходимо прогнать конфигурацию на реальной MKS DLC32 и сохранить резервную копию flash.


## Конфигурация из профиля станка

```bash
python3 scripts/apply_machine_profile.py machine.handdraw-machine.json
python3 scripts/deploy_webui.py handdraw.local \
  --config-file build/machine-config/<имя>/config-commissioning.yaml
```

`--config-file` автоматически включает передачу YAML. Перед заменой контроллерная версия сохраняется в `backups/`, как и при использовании `--config-profile`.
